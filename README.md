# Excel-Sales-Performance-Dashboard
## 📌 Project Overview
This is an end-to-end interactive **Sales Performance Dashboard** built entirely in **Microsoft Excel**. It transforms 2000+ rows of raw sales data into actionable business insights for management to track revenue performance in real-time.

The dashboard is fully dynamic - one click filters update all 6 charts and 4 KPIs instantly.

# 📊 Sales Performance Dashboard - Excel

An interactive Excel dashboard to track Total Revenue, Orders, Quantity Sold, and performance by Region, Product Category, and Sales Channel.

### 📊 Visuals Included
- Revenue by Month (Line Chart)
- Revenue by Region (Bar Chart)
- Revenue by Product Category
- Revenue by Sales Channel (Donut Chart)
- Top 5 Products by Revenue

### 🛠️ Tools Used
- Advanced Excel
- Pivot Tables & Pivot Charts
- Slicers & Timelines
- VLOOKUP / XLOOKUP, SUMIFS
- Data Cleaning & Dashboard Design

### 💡 Key Insights
- Central region generates highest revenue
- Corporate Sales is the dominant sales channel
- Monitors & Laptop Pro 13 are top revenue products

### 📂 How to Use
1. Download the Excel file
2. Enable Macros if asked
3. Use Slicers on left to filter by Region, Product Category, Customer Type, Sales Channel
4. Check SUMMARY sheet for KPIs
